# 项目需求：macOS 3D 应用切换器（类似 Compiz）

## 功能概述
开发一个 macOS 原生应用，实现类似 Compiz 3D 立方体效果的应用程序切换器。该应用需在后台运行，通过全局快捷键呼出，并以 3D 立方体旋转动画展示当前所有打开的应用程序窗口，支持键盘快速切换，松开按键后自动激活选中的应用。

## 交互流程
1. **呼出**：用户按下 `Command + esc `（反引号）组合键时，立即在当前屏幕中央显示切换界面。
2. **切换**：按住 `Command` 键不放，每按一次 esc 键，立方体沿 Y 轴顺时针旋转 90°，显示下一个应用（循环切换）。
3. **退出**：用户松开 `Command` 键时，切换界面平滑消失，并将当前立方体正面展示的应用窗口置于最前并激活（设为当前窗口）。
4. **无应用时**：若没有可切换的应用，不显示界面或显示提示。

## 交互细节
- 切换过程中，立方体旋转动画应流畅（使用 3D 变换），旋转方向始终为顺时针（从上方看）。
- 支持循环切换，即最后一个应用之后回到第一个。
- 切换过程中，应用图标或窗口预览应显示在立方体的各个面上，当前选中的面（正面）高亮或放大。
- 界面背景半透明模糊，覆盖所有其他窗口，但不遮挡系统菜单栏（可选）。

## 技术栈要求
- 使用 SwiftUI 构建 UI，macOS 目标版本 12.0+。
- 使用 `NSEvent` 监听全局键盘事件（需要辅助功能权限）。
- 使用 `NSWorkspace` 获取当前运行的应用列表及窗口信息。
- 3D 效果使用 SwiftUI 的 `.rotation3DEffect` 或 `SceneKit` / `SpriteKit` 嵌入，推荐采用 `CATransform3D` 结合 `CALayer` 实现立方体多面渲染（因为 SwiftUI 原生 rotation3DEffect 只能做单面翻转，真正的立方体需要多个面组合）。
- 窗口管理使用 `NSWindow` 或 `NSPanel`，设置为 `NSWindow.Level.floating` 或 `popUpMenu` 级别。

## UI 设计参考
- 参考 Compiz 的“桌面立方体”插件效果：当前应用位于正面，左右侧面显示前后应用，顶部/底部可显示空白或统一颜色。
- 每个面显示应用的图标、名称，以及可选的窗口缩略图。
- 界面中央显示当前选中的应用，两侧略微显示上一个/下一个应用的边缘（立体感）。
- 支持黑暗模式适配。

## 非功能性需求
- 响应迅速，动画帧率 60fps。
- 内存占用低，后台常驻时不消耗 CPU。
- 首次运行时请求辅助功能权限（通过 `AXIsProcessTrusted` 检测）。

## 额外要求
- 代码结构清晰，使用 MVVM 模式。
- 提供必要的注释和文档。
- 生成完整的 Xcode 工程文件或可运行的单文件 Swift 代码。
